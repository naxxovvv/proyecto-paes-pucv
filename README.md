Proyecto final de programación (PUCV)
En este proyecto se tomo la tabla del DEMRE que dice cuantos puntos PAES te dan segun las respuestas correctas, por lo cual probe funciones matematicas para ver cual se asemeja mas a la tabla
Aca se encuentra lo siguiente: 
- `datos_paes_fisica.csv`: los datos de la tabla.
- `ajuste_paes.py`: el código en Python.
- `ajuste_paes.ipynb`: el mismo código en Google Colab.
- `figuras`: el gráfico con los ajustes.
- `informe.tex`: el informe hecho en LaTeX.
